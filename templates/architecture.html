RAG Workflow

Five-stage pipeline for question-answering from Shakespeare's works.

1

Text Ingestion

Split into 1,000 character chunks with 150 character overlap.

2

Embedding Generation

Convert chunks into 768-dimensional vectors using nomic-embed-text.

3

Vector Storage

Store in Neon Postgres with pgvector for similarity search.

4

Query Processing

Embed question and retrieve top 4 most similar chunks.

5

Answer Generation

Use qwen2:1.5b to generate answers from retrieved context.
